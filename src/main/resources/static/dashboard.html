Escenarios de simulación

¿Se abriría el programa? Cada titulado potencial se inscribe con probabilidad igual a interés × inscripción. Se repite el experimento 5 000 veces y se cuenta en cuántas se alcanza el mínimo de inscritos. La probabilidad de interés sale de las respuestas del origen de datos elegido arriba (reales, demostración o ambos) y cada área de posgrado se simula con la participación que tuvo en esas respuestas. Pulse «Simular y guardar» para dejar la corrida registrada junto con ese origen de datos.

Método utilizado: simulación Monte Carlo

Se repite muchas veces un experimento aleatorio y se cuenta con qué frecuencia ocurre el resultado buscado.

Modelo
Cada titulado potencial se inscribe o no (ensayo de Bernoulli) con probabilidad q = interés × inscripción.
Distribución
Inscritos X ~ Binomial(n, q), con n = titulados potenciales.
Iteraciones
5 000 muestras de X por escenario.
Generador
Números pseudoaleatorios (JDKRandomGenerator) con semilla fija 42: el resultado es reproducible.
Probabilidad de abrir
P = (iteraciones con X ≥ mínimo) / 5 000.
Vínculo con los datos
Interés = proporción de titulados que respondió «SÍ»; cada área recibe su participación entre quienes eligieron un área. Cada corrida guardada conserva el origen de datos y la cantidad de respuestas usadas.
Escenarios
Base y con becas: la beca suma puntos a la probabilidad de inscripción.
